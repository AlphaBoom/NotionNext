# 数据库预览

博客展示数据库的内容样例，完整浏览、搜索、筛选、排序和条目详情交给 Notion 公开页面。

## 展示范围

- 数据库进入视口附近时，读取默认视图的前 **100 条以内**，保留 Notion 保存的筛选和顺序。
- 浏览器先显示 20 条，每次“展开更多预览”再显示 20 条。展开和“搜索预览条目”只处理本次预览数据，不发送额外请求。
- 不提供远程分页、访客筛选/排序、视图切换、查询条件 URL 或精确总数统计。旧 `db_*` / `v` 参数不会改变预览。
- 通过 Notion 返回的 `hasMore` 判断是否还有内容。超过预览范围时显示公开页面入口；未匹配时明确说明“预览中没有匹配条目”，不暗示完整数据库没有结果。
- 标题旁始终提供“在 Notion 中打开”，即使隐藏数据库名称、视图不支持或预览请求失败也保留入口。所有预览条目及属性中的 Notion 页面引用在新标签页打开公开页面。
- 保留表格、画廊、列表和简单看板展示；日历、时间轴等默认视图不查询条目，提供原页入口。
- 表格保留可读列宽、横向滚动、换行开关和方向按钮。手机不固定首列，长描述可占满可视区域。

## 固定预览接口

`GET /api/notion-database?blockId=<32 位小写十六进制 ID>`

仅接受上述一个参数。额外参数、重复 ID、非规范 ID 在读取元数据前返回 400；旧 POST 接口返回 405。没有客户端游标或可修改的 limit、offset、search、filter、sort、viewId、timeZone。

服务端先验证匿名公开访问、站点祖先关系和默认视图，再执行一次固定 `limit: 100` 的 `queryCollection` results reducer。不执行 count aggregation，也不扩大读取范围。即使上游意外返回超过 100 个 ID，也在补全缺失记录前裁剪，最多补全这 100 条。

响应仅保留预览条目的可见字段、标题、封面/分组所需字段，以及被显示属性引用的公开用户姓名/头像、关联页面标题/图标等元数据。不返回条目正文、无关记录或用户邮箱。预览条目少于 100 不会继续查询补足。

## 缓存和开销

成功的固定 GET 响应使用：

```text
Cache-Control: public, max-age=60
CDN-Cache-Control: public, s-maxage=600, stale-while-revalidate=60
```

CDN 缓存命中时无需调用预览函数。实例内另保留最多 20 个预览、每个有效 10 分钟，并合并相同数据库的进行中请求；最多允许 4 个不同数据库的冷请求。失败不缓存，错误响应为 `private, no-store`。

不引入 ISR 预览页面、定时刷新任务或外部缓存服务。缓存只在访问时过期更新；预览可能滞后，最新内容通过 Notion 入口查看。实例缓存和 CDN 缓存有效期可能叠加。

100 条上限约束读取规模，不能保证任意流量下都不超过免费额度。CDN 请求、流量及缓存未命中时的函数执行仍有开销。

缓存依据：[Vercel Cache-Control headers](https://vercel.com/docs/caching/cache-control-headers)。

## 数据源和配置

继续使用 Notion 公开网页匿名请求（`app.notion.com/api/v3`），不使用官方 API Key、Cookie 或 `NOTION_DATABASE_TOKEN`。

- `NOTION_PAGE_ID`：现有站点根页面，继续用于数据库归属检查。
- `NEXT_PUBLIC_NOTION_PUBLIC_HOST`：可选的公开页面域名，本仓库默认 `https://alphaboom.notion.site`。
- `NOTION_DATABASE_TIMEZONE`：默认视图条件的统一站点时区，本仓库默认 `Asia/Tokyo`；不随访客变化，因此所有访客共享同一个预览。

本仓库部署不需增加环境变量。普通文章仍在博客阅读，数据库预览中的详情链接直接前往 Notion。纯静态导出仍需独立承载预览接口。

普通页面正文使用 `fetchCollections: false`，发布索引及 CONFIG 表显式使用 `true`，缓存键分开。正文裁剪保留同步块及嵌套引用，并防止重复遍历；页面链接保留目标元数据，不展开子页面正文和数据库条目。Medium 的站内导航骨架屏和原有加载反馈保留。
